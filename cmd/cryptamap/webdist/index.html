CryptaMap: dashboard not embedded in this binary

This cryptamap binary was built with the committed placeholder dashboard shell (a plain go build), so the web UI is not available. Your scan output on disk is unaffected.

To build a binary with the full dashboard embedded, run make build-serve from the repository root (it builds the dashboard and stages dashboard/dist into cmd/cryptamap/webdist before compiling), then re-run cryptamap serve.
